# صحتي ليبيا | Sehaty Libya

واجهة React عربية باتجاه RTL لاستكشاف الخدمات الصحية في ليبيا. تتضمن البحث عن الأطباء، تصفح المراكز الطبية، تجربة حجز موعد، والبحث التجريبي عن توفر الأدوية.

> هذه نسخة واجهة تجريبية. بيانات الأطباء والمراكز وتوفر الأدوية والحجوزات ليست حقيقية، ولا توجد حالياً واجهة خلفية أو تكامل مع جهات صحية.

## المتطلبات

- Node.js 20.19+ أو 22.12+
- npm

## التشغيل المحلي

```sh
npm install
npm run dev
```

## البناء والتحقق

```sh
npm run build
npm run lint
```

## التقنيات

- React 19 وVite
- Lucide React للأيقونات
- Motion للحركة
